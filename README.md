# TerraX

TerraX is an Earth-observation workbench for forest, land, climate and imagery analysis. Its tools read GeoTIFF rasters, vector boundaries, time-series tables and photos in the browser, compute results with stated scientific methods, and can add an optional Gemini interpretation.

## Tools

The home screen is a grid of tools. Each one takes GIS files, computes results in the browser, draws on the map where relevant, and produces a report you can save or download.

| Tool | Upload | What it computes |
|---|---|---|
| **Forest loss** | Two NDVI (or red/NIR) GeoTIFFs of the same grid, or a Hansen GFC `lossyear` tile (+ optional `treecover2000`) | Forest area, loss and regrowth in hectares, share lost, change map; Hansen loss by year |
| **Land survey** | GeoJSON, KML, GPX, CSV (lat/lon), zipped Shapefile | Area (m², ha, acres), perimeter/length, traverse legs with distances and true bearings, UTM/DMS coordinates, boundary on the map |
| **Weather & climate** | CSV, TSV, XLSX time series or a climate GeoTIFF | Mann–Kendall trend with Theil–Sen slope, seasonal cycle, IMD rainfall categories and rainy days, soil-moisture, humidity, ET and radiation classes |
| **Satellite imagery** | Multiband GeoTIFF or an index time series | True/false-colour composites; NDVI, EVI, SAVI, NDWI, NDMI, NBR, NDBI with stated band roles |
| **Terrain** | DEM GeoTIFF (SRTM, Copernicus, ASTER) | Slope and aspect (Horn 1981), slope classes, hillshade, relief, hypsometric integral |
| **Space & aerial photos** | JPG, PNG, WebP | Vegetation cover (ExG + Otsu), VARI, colour statistics |

Every tool has sample data. The forest, terrain, satellite, survey and photo samples are **synthetic** (generated by `scripts/make-samples.mjs`); do not use them as research data.

Also: a results assistant and an OS Guide (Gemini when configured, built-in answers otherwise), a Reports archive with Markdown and PDF export, planetary telemetry (solar time, sun position, NOAA planetary K-index), and an Earth Engine export manual.

## Run locally

Prerequisite: Node.js 20 or later.

```bash
npm install
cp .env.example .env.local   # optional: add GEMINI_API_KEY for AI features
npm run dev                  # http://localhost:3001
```

The Gemini key is read by the server (the Vite dev server in development, `server/index.ts` in production) and is never included in the browser bundle. Users can also add their own key in **Settings**; it is stored only in their browser.

## Production

```bash
npm run build
npm start          # serves dist/ and the /api proxy on PORT (default 3001)
```

## Scientific notes

- Areas: geographic rasters use exact WGS84 ellipsoid cell areas (authalic latitude); survey plots use UTM with scale-factor correction.
- Forest loss from NDVI thresholds is a proxy and does not apply the FAO forest definition; compare images from the same season.
- The Mann–Kendall test assumes independent observations. Seasonal or autocorrelated series can look significant when they are not, so check the seasonal cycle first.
- Class thresholds are indicative and vary with sensor, season and region.
- Solar time uses the NOAA Solar Calculator equations for the equation of time; sun position and times come from SunCalc.
- The bundled sample data is for demonstration only; its original source is not documented.
